# 📨 RabbitMQ MassTransit Prototype — Inter-Service Communication Prototype • (Archived)

<br>

## 📌 Project Overview

This project is a **RabbitMQ + MassTransit prototype** focused on practicing **message-based communication between microservices** in a .NET environment.  
It demonstrates how to set up a message broker, configure producers and consumers, and use MassTransit to streamline inter-service messaging workflows.  
> 📦 **Archived** — This project is no longer being updated. It’s kept as part of my learning history and serves as a technical reference for future projects.
